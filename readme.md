# patterns_HW

Учебный проект по курсу «Шаблоны проектирования». Разрабатывается программное обеспечение
для автоматизации работы сети ресторанов `ООО Ромашка` согласно
[техническому заданию](Docs/Technicaltask.md).

За основу структуры взят учебный репозиторий
[Patterns2026](https://gitverse.ru/VolovikovAlexander/Patterns2026).

## Направления автоматизации

| 1 | Складской учёт продукции | 1.1 – 1.4 |

## Базовый класс

Все доменные модели наследуются от абстрактного класса
[`AbstractModel`](Src/Abstract.py). Он задаёт для каждой записи:

- `code` — неизменяемый код, создаваемый вместе с объектом;
- `title` — название с контролем пустого значения и обрезкой краевых пробелов;
- `describe()` — абстрактный метод текстового представления, который реализует наследник.

Пример наследника:

```python
from Src.Abstract import AbstractModel


class Warehouse(AbstractModel):
    """Склад — место хранения номенклатуры."""

    def __init__(self, title: str) -> None:
        super().__init__()
        self.title = title

    def describe(self) -> str:
        return f"Склад «{self.title}»"
```
