# Описание доменов и сущностей

Документ описывает предметную область, разобранную по [техническому заданию](Technicaltask.md)
для сети ресторанов `ООО Ромашка`. Сущности сгруппированы по доменам, соответствующим
шести направлениям учёта из ТЗ.

Все перечисленные сущности наследуются от абстрактного класса
[`abstract_model`](../Src/Core/Abstract.py) и получают от него код записи (`code`)
и наименование (`title`).

## 1. Организационная структура

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Организация | Юридическое лицо сети: реквизиты, ИНН, адрес, контакты | Владеет **Рестораном** и **Производственным цехом**; выступает стороной в документах финансового учёта |
| Ресторан | Точка сети (всего 10). Хранит адрес, координаты для расчёта доставки и режим работы 10:00–22:00 | Принадлежит **Организации**; имеет **Помещения** и **Склады**; относится к **Типу ресторана**; обслуживает **Районы доставки**; место работы **Сотрудников** |
| Тип ресторана | Перечисление режима обслуживания: только доставка, только зал, комбинированный | Определяет поведение **Ресторана** при распределении **Заказа на доставку** |
| Производственный цех | Обособленное круглосуточное подразделение, где готовятся заготовки и хранятся централизованно закупаемые мясные и молочные продукты | Принадлежит **Организации**; содержит **Склады** (в том числе холодильники); исполняет **Заказ на производство** |
| Помещение | Физическое помещение подразделения: кухня, зал, кладовая, холодильная камера | Входит в **Ресторан** либо **Производственный цех**; с ним связан **Склад** |

## 2. Складской учёт

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Группа номенклатуры | Классификатор номенклатуры: сырьё, полуфабрикаты, готовые блюда, упаковка. Удаление запрещено, если в группе есть номенклатура, участвующая в складском учёте | Содержит **Номенклатуру**; может быть отобрана в **Частичной инвентаризации** |
| Номенклатура | Позиция учёта: продукт, полуфабрикат, блюдо или упаковка. Удаление блокируется при наличии складских движений | Входит в **Группу номенклатуры**; измеряется в **Единице измерения**; фигурирует в **Складской транзакции**, **Остатке**, **Технологической карте**, **Строке инвентаризации**, **Позиции меню** |
| Единица измерения | Единица учёта (кг, г, л, шт) с коэффициентом пересчёта к базовой единице | Используется **Номенклатурой**, **Строкой технологической карты**, **Складской транзакцией** |
| Склад | Место хранения номенклатуры. Каждый склад привязан к помещению | Связан с **Помещением**; хранит **Остатки**; фигурирует в **Складской транзакции**, **Инвентаризации**, **Заказе на пополнение склада** |
| Остаток номенклатуры | Текущее количество конкретной номенклатуры на конкретном складе | Ссылается на **Склад** и **Номенклатуру**; пересчитывается из **Складских транзакций**; сверяется **Инвентаризацией** |
| Складская транзакция | Элементарное движение номенклатуры: приход или расход с указанием склада, количества, документа-основания и ответственного | Ссылается на **Склад**, **Номенклатуру**, **Единицу измерения**, **Сотрудника** и документ-основание (**Выпуск продукции**, **Утилизация**, **Заказ на пополнение склада**) |
| Инвентаризация | Документ сверки учётных и фактических остатков. Плановая проводится ежемесячно по всей номенклатуре склада | Относится к **Складу**; содержит **Строки инвентаризации**; проводится **Сотрудником** |
| Частичная инвентаризация | Вариант инвентаризации по отдельной группе номенклатуры, проводится несколько раз в месяц | Разновидность **Инвентаризации**; ограничена **Группой номенклатуры** |
| Строка инвентаризации | Позиция документа сверки: учётное количество, фактическое количество, отклонение | Входит в **Инвентаризацию**; ссылается на **Номенклатуру** и **Единицу измерения** |

## 3. Производственный учёт

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Технологическая карта | Рецептура приготовления полуфабриката или блюда: состав, выход, описание процесса. Может быть составной — включать другую технологическую карту | Состоит из **Строк технологической карты**; ссылается на результирующую **Номенклатуру**; используется в **Приготовлении полуфабриката**, **Приготовлении блюда**, **Выпуске продукции** |
| Строка технологической карты | Компонент рецептуры: номенклатура либо вложенная технологическая карта с количеством и единицей измерения | Входит в **Технологическую карту**; ссылается на **Номенклатуру** или вложенную **Технологическую карту** и **Единицу измерения** |
| Приготовление полуфабриката | Операция производства заготовки по технологической карте с расходом сырья | Ссылается на **Технологическую карту**, **Склад**, **Сотрудника**; порождает **Складские транзакции**; применяет **Режим списания** |
| Приготовление блюда | Операция производства готового блюда, в том числе из ранее приготовленных полуфабрикатов | Ссылается на **Технологическую карту**, **Склад**, **Сотрудника**; порождает **Складские транзакции**; применяет **Режим списания** |
| Выпуск продукции | Документ оприходования произведённой продукции на склад | Ссылается на **Технологическую карту**, **Склад**, **Сотрудника**; порождает приходные **Складские транзакции**; может закрывать **Заказ на производство** |
| Утилизация продукции | Документ списания непригодной продукции с указанием причины | Ссылается на **Склад**, **Номенклатуру**, **Сотрудника**; порождает расходные **Складские транзакции** |
| Режим списания | Перечисление правил расхода: с блокировкой при недостатке остатка и под сальдо (списание без блокировки, остаток уходит в минус) | Задаётся в **Приготовлении полуфабриката**, **Приготовлении блюда**, **Утилизации**; влияет на **Остаток номенклатуры** |

## 4. Курьерская служба

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Район доставки | Географическая зона, в пределах которой выполняется доставка | Обслуживается **Ресторанами** с доставкой; имеет **Тариф доставки**; указывается в **Заказе на доставку** |
| Тариф доставки | Стоимость доставки в конкретный район с периодом действия | Относится к **Району доставки**; учитывается в сумме **Заказа на доставку** |
| Меню доставки | Отдельный от зального меню перечень блюд, доступных к доставке | Принадлежит **Ресторану**; состоит из **Позиций меню** |
| Позиция меню | Блюдо в меню доставки с ценой и обязательной упаковкой | Входит в **Меню доставки**; ссылается на **Номенклатуру** (блюдо) и **Упаковку** |
| Упаковка | Номенклатура тары, автоматически добавляемая к каждому блюду в доставке | Является **Номенклатурой**; включается в **Позицию меню** и списывается **Складской транзакцией** |
| Курьер | Сотрудник, выполняющий доставку заказа клиенту | Разновидность **Сотрудника**; закреплён за **Рестораном**; исполняет **Заказ на доставку** |
| Клиент | Получатель заказа: контактные данные и адрес доставки | Оформляет **Заказ на доставку**; адрес попадает в **Район доставки** |

## 5. Финансовый учёт

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Группа контрагентов | Классификатор контрагентов: поставщики, покупатели, прочие | Содержит **Контрагентов** |
| Контрагент | Юридическое или физическое лицо, с которым ведутся взаиморасчёты | Входит в **Группу контрагентов**; указывается в **Документе поступления**, **Документе списания**, **Финансовой транзакции** |
| Тип оплаты | Перечисление форм расчёта: наличные, банковский перевод, прочее | Указывается в **Документе поступления**, **Документе списания**, **Финансовой транзакции** |
| Документ поступления | Регистрация прихода денежных средств от контрагента | Ссылается на **Контрагента**, **Тип оплаты**, **Сотрудника**; порождает **Финансовую транзакцию** |
| Документ списания | Регистрация расхода денежных средств в пользу контрагента | Ссылается на **Контрагента**, **Тип оплаты**, **Сотрудника**; порождает **Финансовую транзакцию** |
| Финансовая транзакция | Элементарное движение денежных средств, формирующее сальдо взаиморасчётов | Ссылается на **Контрагента**, **Тип оплаты** и документ-основание; фиксирует **Сотрудника** |

## 6. Учёт персонала

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Сотрудник | Карточка работника: ФИО, должность, категория, тарифная ставка. Удаление блокируется, если сотрудник участвовал в складском, оперативном или финансовом учёте | Работает в **Ресторане** или **Производственном цехе**; относится к **Категории сотрудника**; закреплён за **Графиком работы**; выступает ответственным во всех учётных документах |
| Категория сотрудника | Перечисление направлений: производство (сменный режим), обслуживание и управление (8 часов в день, кроме выходных и праздников) | Определяет допустимый **График работы** **Сотрудника** |
| График работы | Правило рабочего времени: сменный или ежедневный, длительность смены не более 8 часов, тарифная ставка | Назначается **Сотруднику**; порождает **Смены**; задаёт норму для **Отметки рабочего времени** |
| Смена | Запланированный интервал работы по графику с датой начала и окончания | Принадлежит **Графику работы**; относится к **Сотруднику**; сопоставляется с **Отметкой рабочего времени** |
| Отметка рабочего времени | Факт начала и завершения работы сотрудника. Часы сверх нормы графика оплачиваются по двойному тарифу | Ссылается на **Сотрудника** и **Смену**; служит основанием для **Начисления оплаты труда** |
| Начисление оплаты труда | Расчёт вознаграждения за период: часы по тарифу плюс переработка по двойному тарифу | Ссылается на **Сотрудника**, **Отметки рабочего времени**, **График работы**; может порождать **Документ списания** |

## 7. Оперативный учёт

| Наименование сущности | Описание | Связи с другими сущностями |
| --- | --- | --- |
| Заказ на доставку | Заказ клиента, направляемый в ближайший работающий на доставку ресторан для минимизации расстояния | Ссылается на **Клиента**, **Ресторан**, **Район доставки**, **Тариф доставки**, **Курьера**, **Сотрудника**; содержит **Строки заказа** из **Меню доставки** |
| Заказ на пополнение склада | Заявка администратора ресторана в производственный цех на заготовки и централизованно закупаемые продукты к началу рабочего дня | Ссылается на **Ресторан**, **Склад**, **Сотрудника**; содержит **Строки заказа**; исполняется **Заказом на производство** и **Складскими транзакциями** |
| Заказ на производство | Задание производственному цеху на изготовление продукции по технологическим картам | Ссылается на **Производственный цех**, **Технологические карты**, **Сотрудника**; содержит **Строки заказа**; закрывается **Выпуском продукции** |
| Строка заказа | Позиция любого из заказов: номенклатура, количество, единица измерения, цена (для доставки) | Входит в **Заказ на доставку**, **Заказ на пополнение склада** или **Заказ на производство**; ссылается на **Номенклатуру** и **Единицу измерения** |
| Статус заказа | Перечисление состояний обработки: создан, принят, в работе, выполнен, отменён | Описывает состояние всех видов **Заказов** |
